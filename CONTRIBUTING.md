# Contributing to AION Protocol

AION is an open infrastructure project for the Autonomous AI Agent era.

## How to Contribute

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Run tests: `pytest tests/ -v`
5. Push and open a Pull Request

## What We Need

- Python/backend engineers
- AI agent framework integrations (LangChain, CrewAI)
- Documentation improvements
- Test coverage
