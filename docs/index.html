// how it works

Every action needs
a signed token

No token, no action. It's that simple. AION sits between your AI agent and the outside world.

01 —

Request Authority

Agent calls /issue with a scope. AION returns an RSA-signed, time-limited token.

02 —

Enforce

Before acting, agent presents the token. AION verifies scope, signature, and expiry.

03 —

Consume & Block

Token is consumed on use. Any replay attempt is permanently blocked.

04 —

Revoke Anytime

Revoke any token instantly. Agent loses authority immediately — no waiting.
