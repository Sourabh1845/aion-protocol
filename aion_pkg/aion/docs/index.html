// the problem

AI agents act.
Who controls them?

🤖

Agents act without permission

Your AI agent deletes a file, sends an email, or calls an API — without any authorization check.

→ AION blocks unauthorized actions
🔄

Same action runs twice

A bug or replay attack causes an agent to execute the same action multiple times — no way to stop it.

→ AION tokens are one-time use
🎯

Agents exceed their scope

Agent authorized to read data starts writing or deleting — scope creep with no enforcement layer.

→ AION enforces exact scope
// quickstart

Up and running
in 30 seconds

01 —

Install

One pip command — no config needed.

02 —

Issue Token

Agent requests authority for a specific action.

03 —

Enforce

AION verifies — then allows or blocks the action.

terminal
$ pip install aion-protocol
issue a token — POST /issue
# Agent requests authority before acting
curl -X POST https://aion-protocol.onrender.com/issue \
  -H "X-AION-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{"scope": "delete.file", "issuer": "my-agent"}'
 
{
  "jti": "a32400ea-228d-4e7c...",
  "scope": "delete.file",
  "signature": "TzijYEpR6CVQ...",
  "expires_at": "2026-04-10T10:00:00Z"
}
enforce — POST /enforce
# Agent presents token — AION allows or blocks
curl -X POST https://aion-protocol.onrender.com/enforce \
  -d '{"jti": "a32400ea...", "scope": "delete.file"}'
 
✓ {"status": "ENFORCED"}  ← action allowed
✗ {"error": "CONSUMED"}  ← replay blocked
✗ {"error": "SCOPE_MISMATCH"}  ← wrong scope blocked
