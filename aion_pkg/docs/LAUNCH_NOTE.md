# AION Launch Note

AION is a security layer for AI agents.

It helps developers scan risky agent tools, block unsafe actions, and create proof of what happened.

## What is new

AION now includes:

- AION Guard
- AION Receipts
- AION Scan

## Demo flow

1. Run: aion scan .
2. Run: aion guard-demo
3. Run: aion receipts 10

## One-line pitch

AION helps developers scan and secure AI agent tool calls before they cause damage.

## Short post

AI agents are moving from chat to action.

They can run commands, call APIs, access files, and touch databases.

I am building AION: a security layer that scans risky agent tools, guards dangerous actions, and creates proof of what happened.
